# 🚀 SmartVenue Navigator

### *Navigate crowds in real-time. Reduce wait times. Move smarter.*

---

## 📌 Problem Statement

Large-scale venues such as stadiums and event arenas often face:

* 🚶‍♂️ Crowd congestion
* ⏳ Long waiting times
* ❓ Lack of real-time guidance for attendees

These challenges lead to poor user experience and inefficient crowd management.

---

## 💡 Solution Overview

**SmartVenue Navigator** is a real-time intelligent system that:

* Monitors crowd density across venue zones
* Estimates waiting times dynamically
* Provides actionable, data-driven recommendations

Instead of just displaying data, the system actively **guides users to make better decisions and avoid congestion**.

---

## ✨ Key Features

* 📊 **Real-Time Crowd Monitoring**
  Track occupancy and density across different zones

* 🧭 **Smart Recommendations**
  Suggest optimal zones and highlight areas to avoid

* ⏱️ **Wait-Time Estimation**
  Predict delays based on real-time density

* 📈 **Trend Detection**
  Identify whether zones are becoming crowded or clearing

* 🎛️ **Interactive Dashboard**
  Simulate occupancy changes and observe system behavior

---

## 🏗️ System Architecture

```
Frontend (React + Vite)
        ↓
Backend (Node.js + Express)
        ↓
Firebase Firestore (Real-time Database)
```

---

## 🛠️ Tech Stack

**Frontend**

* React (Vite)
* CSS

**Backend**

* Node.js
* Express

**Database**

* Firebase Firestore

**Cloud & Deployment**

* Google Cloud Run
* Google Cloud Build
* Artifact Registry

---

## ⚙️ How It Works

1. Crowd data is stored in **Firebase Firestore**
2. Backend processes:

   * Density calculations
   * Wait-time estimation
   * Smart recommendations
3. Frontend fetches real-time data via deployed APIs
4. Users interact with the dashboard and simulate crowd scenarios
